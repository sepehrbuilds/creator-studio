# Creator Studio

> **Built for my own use. Not distributed.**

The pipeline behind my two short-video channels, [Straight From a Doctor](https://www.youtube.com/@straightfromadoc)
and [Worth Knowing](https://www.youtube.com/@worthknowingbrief). It takes each video from idea to published:

1. **Topics:** a weekly shortlist, checked against what the channel has already covered.
2. **Script and evidence:** sources first, then a short script.
3. **Video:** local voice, word-synced captions and animation, rendered to MP4.
4. **Publishing:** upload to YouTube and Instagram after a preview.
5. **Stats:** a small web dashboard showing both channels in one place.
